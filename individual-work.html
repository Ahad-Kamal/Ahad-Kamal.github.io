Solo Projects

FBX Model Viewer

C++ Animation FBX

Overview

Created a system for loading and rendering fbx files using the Autodesk FBX SDK.

Features

Coded a pipeline for importing fbx files involving retrieving the model’s vertices, uvs, normals, joints, and animation data, then structuring the data into custom classes that server as wrappers for easier use.


The result is a fully rendered, texured, lit model, with animation keyframes being calculated using the bone hierarchy on the CPU and the mesh then skinned and animated on the GPU.


Implemented a custom .model file type that gets baked the first time the model is loaded, which is then instead parsed and loaded in manually without having to re-retrieve the data from the fbx file. This resulted in a 60% speed increase on load times.

Net Chess 3D

C++ Graphics Networking

Overview

Recreated the classic game of chess in my engine that accounts for piece movement rules, capturing logic, and proper turn order.

Features

Coded a manual obj file parser that reads in vertex, UV, and normal data and then outputs the data into a complete 3D model, with additional supporting functions that can create normals, tangents, and bitangents for models that do not contain this information.


Implemented a more sophisticated BlinnPhong shader that supports multiple directional lights, point lights, spotlights, specularity, glossiness, emissivity, and several debug shading modes that isolate each of these lights and values.


Incorporated the third party ImGui library for easy UI creation and implementation, including UI functionality for controlling light values and debug modes.
